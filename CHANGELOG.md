# Histórico de versões

As versões são criadas automaticamente a cada alteração na branch `main`
(veja a aba **Releases** no GitHub). Este arquivo resume os marcos principais.

- Importação da planilha “Filtro de Demandas” com deduplicação e fotos
- Busca global e filtros combinados
- Perfis Diretoria / Supervisão / Operação com bloqueio no banco (RLS)
- Auditoria de todas as alterações
